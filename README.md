# Pratikum 3 CSS Dasar
## Pratikum CSS Dasar

## 1.Eksperimen dilakukan dengan mengubah dan menambahkan beberapa properti serta nilai pada CSS, seperti warna teks, ukuran huruf, warna latar belakang, jarak, garis tepi, dan posisi teks. Perubahan tersebut dilakukan untuk melihat pengaruh setiap properti CSS terhadap tampilan halaman HTML pada browser. 

## 2. Perbedaan h1 dengan #intro h1 adalah h1 digunakan untuk mengatur semua elemen heading satu yang ada pada halaman. Sedangkan #intro h1 hanya digunakan untuk mengatur elemen h1 yang berada di dalam elemen yang memiliki ID intro. Jadi, #intro h1 lebih spesifik dibandingkan h1.

## 3. Jika terdapat CSS internal, CSS eksternal, dan CSS inline yang diterapkan pada elemen yang sama, maka CSS inline pada umumnya akan ditampilkan karena memiliki tingkat prioritas yang lebih tinggi dibandingkan CSS internal dan eksternal biasa. Contohnya, jika CSS internal dan eksternal memberikan warna biru pada teks, tetapi CSS inline memberikan warna merah, maka teks yang ditampilkan pada browser akan berwarna merah.

## 4. Jika sebuah elemen HTML memiliki ID dan Class sekaligus, seperti <p id="paragraf-1" class="text-paragraf">, kemudian ID dan Class tersebut memiliki deklarasi CSS untuk properti yang sama, maka deklarasi dari ID akan ditampilkan. Hal ini karena selector ID memiliki tingkat prioritas atau specificity yang lebih tinggi dibandingkan selector Class. Jadi, #paragraf-1 lebih diprioritaskan daripada .text-paragraf.
